# Real map source and verification notes

The initial public place is **Grady Memorial Hospital, 80 Jesse Hill Jr Drive SE, Atlanta, GA 30303**. The [official Grady location page](https://www.gradyhealth.org/locations/grady-memorial-hospital/) matches the name, number, city, state and postcode on [OSM way 270880941](https://www.openstreetmap.org/way/270880941); OSM spells the street suffixes “Junior” and “Southeast.” The bounded official Overpass lookup returned longitude **−84.382073**, latitude **33.7517332**. These coordinates are the way's display center, not an entrance or a user's location. OSM's last edit is 2020-12-23. There is no field inspection date or sourced access claim.

`src/navigation/public-seed.json` is a minimal, dated ODbL public-source snapshot. It is separate from the fictional campus graph. `node scripts/import-grady.mjs` performs one explicit OSM lookup, validates the address against the official page, and replaces the seed only after those checks pass. The app does not geocode at startup and does not use public Nominatim. No hospital partnership or indoor deployment is implied.

## Actual 3D evidence

On 2026-10-31, the [OpenFreeMap Liberty style](https://tiles.openfreemap.org/styles/liberty) already contained one `building-3d` extrusion layer, using `openmaptiles / building` and `render_height / render_min_height`. Its vector source resolved to the `20261025_080012_pt` snapshot. Tile **14/4351/6558** contained **74 building features**, of which **67** had a positive render height and were not hidden in 3D. An exact point-in-polygon check at the saved Grady center found a footprint with provider `render_height=5`, `render_min_height=0`.

**That value is a visualization estimate, not a measured five-meter hospital height.** The original Grady OSM way has no `height` or `building:levels` tag. [OpenMapTiles defines these render fields as approximations](https://openmaptiles.org/docs/schema/#building); defaults and level-derived estimates may be present. The app now labels those estimates visibly. No fabricated hospital cubes are added. The saved source evidence and small matched polygon are in `docs/grady-building-evidence.json`; rerun `node scripts/inspect-map-source.mjs` to verify the provider again. On hosts using an enterprise system certificate store, Node 24 may require `node --use-system-ca`.

MapLibre reuses existing extrusion layers, retains labels and attribution, adds a missing layer only for the documented OpenFreeMap schema, and avoids duplicate custom layers when styles reload. List/2D/3D, zoom, keyboard pan, orientation reset, result fitting and list selection remain available. The browser reports whether actual rendered height-bearing features are visible; pitch alone does not qualify as 3D geometry. [Current OpenFreeMap setup](https://openfreemap.org/quick_start/) and [MapLibre 3D guidance](https://maplibre.org/maplibre-gl-js/docs/examples/display-buildings-in-3d/) were checked against installed MapLibre 6.16.0 and its bundled ESM worker.

## Discovery and location

The replaceable Overpass adapter uses explicit GET requests to the official endpoint because POST returned HTTP 406 in this development environment. Queries remain bounded (800 m in the UI; 100–1500 m in the adapter), limited in response bytes/elements, cancellable and deduplicated by OSM type/ID. One request runs at a time with at least 1.5 seconds between network requests. Six public responses stay in session memory for five minutes; expired results can be offered explicitly with their original retrieval date after a failure. This is per-client throttling, not a global deployment quota. A larger public deployment needs its own appropriate service arrangement. No retries on pan or autocomplete calls are made.

Browser location starts only from **Use my location**. It shows source, accuracy radius and update time, supports Stop tracking, ignores late callbacks, and clears watchers on unmount, mode changes and app hiding. Manual coordinates are labeled **Selected starting point**. Only the latest point is held in component memory; no history, geographic heading, indoor floor or room is inferred. Map tile requests reveal the visible area; discovery sends its center only when requested.

## Optional Google provider

No authorized usable Google project/key was present. The provider boundary lists the functioning OpenFreeMap default and disables Google photorealistic 3D; it does not load Google's engine. A Google implementation remains **not implemented / optional configuration required**, not a tested secondary engine.

The [current Google Demo Key documentation](https://developers.google.com/maps/documentation/javascript/demo-key) (page updated 2026-10-22, checked 2026-10-31) restricts eligibility to personal Google accounts outside prohibited territories. It lists a limited feature set including 2D/3D map rendering and states that daily limits pause service until the next day; its fetched quota section did not expose numerical limits. Do not assume unlimited quotas or that every 3D feature is entitled. Recheck the project's visible limits, [3D setup and billing](https://developers.google.com/maps/documentation/javascript/3d/overview), supported channel, referrer/API restrictions and attribution before implementing a configured alternative. Production requires the user's own approved setup and billing decision; this app provisions none.
